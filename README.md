## Entry

`main.py` (Python 3.13, harness program/v1) writes one line about a small good thing that happened today to `/output/entry.txt`:

> My neighbour's cat followed me home from the bus stop, sat on my doorstep, and waited until I said goodnight before trotting off.

(129 characters; gate: 1-200 characters, UTF-8.)

## How it works

No network, no randomness, no input — the program writes a fixed string, so
every run produces byte-identical output. See `BUILD-NOTE.md` for the
verification evidence.
